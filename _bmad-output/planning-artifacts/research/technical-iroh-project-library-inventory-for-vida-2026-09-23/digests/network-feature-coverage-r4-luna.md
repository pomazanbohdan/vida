## VIDA-specific reading

The network/mobile gate is endpoint identity and lifecycle + route/discovery behavior + a host-owned mobile reconnect policy + an explicit Rust/Flutter bridge contract. A sample’s VPN/TUN implementation is relevant only when its endpoint lifecycle/platform wrapper informs those gates; VPN routing is separate from VIDA’s app-level peer connectivity requirement. None of these inspected projects documents a drop-in Flutter plugin. Nexa Android offers the clearest app-level Android handover example; `iroh-ffi` offers the broadest packaged UniFFI transport binding example; Rayfish and RDS expose broader product-level endpoint/service implementations. These are evidence slices for separate prototype checks, not a production selection.
