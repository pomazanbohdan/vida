## Reading note

The gate is function-level. Irokle most directly packages signed causal operations, membership checks and bounded sync; iroh-db packages typed signed commits, authorization, local transactions and rebuild verification; Wyrd's main differentiator is immutable file/snapshot storage and encryption with some runtime gaps; Kukuri demonstrates an integrated application split among docs, blobs, hints and local projections. This describes evidenced surface only; it makes no production or selection recommendation.
