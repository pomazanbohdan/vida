# Identity and recovery — round 1

- claim: W3C DID Core separates a persistent identifier from mutable verification methods and service endpoints; each DID method must define update semantics. source: https://www.w3.org/TR/did-core/ ; publisher: W3C; pub_date: 2022-07; accessed: 2026-09-29; confidence: high; class: architecture pattern.
- claim: Nostr NIP-05 maps a human-readable domain address to a public key, but clients follow the key rather than silently replacing identity when an address mapping changes. source: https://github.com/nostr-protocol/nips/blob/master/05.md ; publisher: Nostr protocol maintainers; pub_date: undated living spec; accessed: 2026-09-29; confidence: high; class: interoperability.
- claim: Matrix IDs include the homeserver domain, illustrating a server-bound address distinct from portable cryptographic identity. source: https://spec.matrix.org/unstable/appendices/ ; publisher: Matrix.org Foundation; pub_date: living spec; accessed: 2026-09-29; confidence: high; class: interoperability.
- claim: Element lets a user verify a new device with a recovery key after all prior devices are lost, but account-provider login and server-held encrypted key backup remain part of the flow. source: https://element.io/help ; publisher: Element; pub_date: undated living help; accessed: 2026-09-29; confidence: high; class: recovery pattern.
- claim: Delta Chat adds a second device using an existing device's QR transfer or imports a backup file; after transfer the devices are independent. source: https://delta.chat/en/help ; publisher: Delta Chat; pub_date: undated living help; accessed: 2026-09-29; confidence: high; class: recovery pattern.
- claim: SimpleX exports an encrypted local database but warns that reusing the same copied profile concurrently on multiple devices or restoring an old copy can disrupt connections. source: https://simplex.chat/docs/guide/chat-profiles.html ; publisher: SimpleX; pub_date: undated living help; accessed: 2026-09-29; confidence: high; class: contrary evidence.

Inference: no cited reference proves a globally current revocation state from an isolated, potentially stale backup alone. A VIDA public node can be a current-history witness for a linked account without becoming the owner of the private Persona; no node means local recovery must disclose freshness uncertainty.
