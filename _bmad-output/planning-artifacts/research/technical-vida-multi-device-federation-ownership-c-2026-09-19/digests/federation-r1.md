## Leads / open checks

- No source in this bounded set establishes a generic federated-node requirement to host arbitrary third-party apps or run user business workflows. App logic and deployment remain product decisions; further product-specific protocol/capability design is needed.
- Matrix's optional E2EE is evidence for encrypted communication history, not proof of a purpose-built private mailbox with retention, delivery guarantees, and key-recovery policies. Those properties need a separate design/specification.
- AT PDS keeps canonical repo and key material; app-level data authority for derived views and private state needs explicit product rules beyond identity resolution. Iroh endpoint keys likewise do not settle account ownership.
