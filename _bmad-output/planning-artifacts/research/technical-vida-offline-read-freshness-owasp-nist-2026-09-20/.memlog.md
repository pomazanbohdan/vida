- (claim) ref=[1] status=unverified class=mobile-session pub=unknown — OWASP MASWE-0024 requires mobile sensitive data inaccessible after session termination and recommends clearing tokens, cached data, memory and screen content; only one independent publisher in scope.
- (claim) ref=[2] status=verified class=web-session pub=unknown — Session timeouts are risk-based and server-side; NIST independently confirms explicit session expiration and authority-side enforcement, but not offline cache expiry.
- (claim) ref=[3] status=verified class=auth-session pub=2025-07 — NIST SP 800-63B-4 gives AAL1 30-day and AAL2 24-hour overall reauthentication recommendations; these concern authenticated sessions, not VIDA offline membership freshness.
- (claim) ref=[4] status=unverified class=mobile-storage pub=unknown — OWASP MASVS-STORAGE-1 requires secure storage of sensitive data; no offline-read TTL is specified in that control.
- (question) No OWASP-prescribed universal offline-read revocation timeout found in reviewed official sources. VIDA must choose a product risk budget for control-head freshness; this is not an OWASP value.
