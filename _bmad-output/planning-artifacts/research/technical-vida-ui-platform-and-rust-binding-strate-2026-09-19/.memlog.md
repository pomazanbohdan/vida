- (decision by researcher) Use breadth-first fan-out, deep preset, high validation, current primary sources, and a fresh-context red-team pass. Candidate field includes native UI, Kotlin/Compose Multiplatform, Flutter, React Native, Tauri/webview, web/PWA, credible Rust-native UI, and mixed shells.
- (direction by user) Working hypothesis: Flutter for the mobile UI, Rust for the shared core/runtime, and Tauri for Windows. Treat as a candidate to validate, not a final platform decision.
- (source) Primary source batch: Flutter supported platforms/FFI/background/accessibility/ABI; flutter_rust_bridge 2.13 and cancellation; Tauri architecture/IPC/WebView2/plugins/releases.

- (claim) ref=[2] status=verified class=integration pub=2026-09 - Dart FFI provides a native C-symbol path for Flutter mobile/desktop but not the same path for Flutter web.
- (claim) ref=[3] status=verified class=platform/runtime pub=2026-09 - Flutter background isolates have message-passing and host-callback limits; web has no isolates and compute runs on the main thread.
