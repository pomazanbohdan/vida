## Selection consequence

- Flutter mobile + Rust + Tauri Windows is coherent as a *candidate* only if both bindings implement a single versioned application contract and pass identical domain/conformance cases.
- Flutter Windows is a required comparator: it reuses Flutter UI and FRB; Tauri requires a distinct web UI, IPC/event path and accessibility QA, but may suit Windows/web workflows. The choice should be measured, not presumed from Rust affinity.
- Open decisions: v1 platform priority; City Portal sidecar topology and authority; browser delivery profile; compatibility window; specific background/notification/secure-storage OS adapters; performance and battery thresholds.
