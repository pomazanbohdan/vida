# VIDA chat — ui-ux-pro-max experiment

Status: mobile chat compactness approved by the user; palette, typography, icon style and global shell remain review concepts. Baseline: `layout-chat-mobile-v2.png`. New screen: `chat-skill-v3.html` / `chat-skill-v3.png`. Comparison slide: `chat-skill-comparison-2026-09-22.html` / `.png`.

The local `ui-ux-pro-max` product search matched **Chat & Messaging App** and recommended restrained minimalism, subtle interaction feedback and differentiated message bubbles. Its broad design-system query returned a marketing-page pattern and high-risk neumorphism, so those outputs were rejected as inapplicable to a native chat. The `slides` skill supplied the before/after split-slide pattern. Both images were rendered from local HTML in headless Chrome; no new product color or font decision was approved.

Compared with v2, the experiment keeps Persona, Space, Chat/Forum and four primary destinations. It compresses message chrome; gives incoming and outgoing messages distinct structure; adds per-message group delivery (`Доставлено 2/4`) while keeping `Онлайн` tied to the current device; and displays the linked Project task as a shorter resource card. Text/icon contrast, named controls, visible focus and 44px-or-larger controls are design targets in the prototype. The static screenshot does not prove Dynamic Type, screen-reader behavior, responsive layouts or Flutter implementation.

Review question: is this calmer, denser chat direction preferable to the larger, more conversational v2, or should VIDA retain the original message size and apply only the clearer delivery/resource patterns?
