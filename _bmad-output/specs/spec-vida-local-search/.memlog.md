- (direction) Distill approved PRD FR-11/FR-21, REQ-CLIENT-022, identity SPEC-ID-009, ACL REQ-ACL-020, shared rights freshness and UX search primitive into VIDA local-search kernel; preserve open file-content and indexing-provider choices.
- (capability) CAP-1 intent: user searches locally across currently authorized synchronized Resources of active Persona; success: Messenger, Note, Task, Forum, File and Contact entries are discoverable only when indexed locally and permitted.
- (capability) CAP-2 intent: user narrows results by Persona/actor, Space, AppInstance, author and Resource type; success: same query returns correctly scoped results and no results from unlinked Persona without explicit cross-account grant.
- (capability) CAP-3 intent: user can identify partial offline coverage; success: UI states local/synchronized coverage and does not imply remote or non-downloaded material was searched.
- (capability) CAP-4 intent: user opens search result in its source context; success: fresh read check precedes title/snippet/resource navigation and forbidden result is not revealed.
- (capability) CAP-5 intent: system reconciles local search projection with canonical authorized Resources; success: revocation, read-lock, deletion/tombstone and account switch suppress prior results/snippets and rebuild does not resurrect them.
- (constraint) Search is shared mandatory Core capability; index is derived local projection and not an authority or external search service.
- (constraint) Only current account context and grants may expose results; resource-scoped guest grants do not expose unrelated Space metadata via title, snippet, count, filter or backlinks.
- (constraint) Shared Space rights expiry after seven days or effective removal must deny managed search even offline; Personal Space follows its own identity policy.
- (constraint) Private content must not be sent to an external search service by default; local index protection and revocation negative tests are release-gating, implementation choice remains open.
- (decision) Non-goals: remote/cloud search by default, cross-Persona aggregation without separate authorization, search-result authority over canonical Resource state; no OCR or full-file-content commitment without explicit decision.
- (question) Which content fields are searchable in Release 1 for Files, attachments and ContactCards, and is OCR/full-file-content indexing in scope? PRD requires Resource search but leaves extraction depth open.
- (question) What local index/storage provider and encryption/rebuild strategy passes platform conformance and rights revocation fixtures? No provider selected.
