- (capability) CAP-1 intent: user creates personal or shared note, structured document and section in a Space; success: addressable Resource identity and authorized content survive local restart.
- (capability) CAP-2 intent: user edits rich text with blocks and attachments; success: supported formatting, stable block relations and file links persist without duplicating file payload.

- (capability) CAP-5 intent: user relates Notes to task, chat, forum topic and file while searching knowledge; success: explicit links navigate authorized targets and local search excludes inaccessible content.

- (constraint) Read/search/attachments/backlinks honor current scoped ACL; a resource relation alone never grants target access.
