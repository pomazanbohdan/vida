# Стан обговорення контурів VIDA

Це огляд стану документації, а не нове архітектурне рішення. «Обговорено» не означає «контур завершено»; матеріал у `research/` не стає вимогою без рішення користувача. Оцінка спирається на [послідовність контурів](discussion-roadmap.md), [реєстр питань](open-questions.md), [індекс нормативних документів](../README.md) і [трасування досліджень](research-traceability.md).

Формальний рівень стандарту, матриця допоміжних технологій і мобільний gate потребують рішення; installed-build перевірки не виконано.

[BMad approval process kernel](../../_bmad-output/specs/spec-vida-approval-process/SPEC.md) звів погоджені `REQ-EFFECT-012–014` до CAP-1–CAP-5 і APR-F01–F13: рекомендований default пакета, вибір Admin для кожного процесу, три ручні профілі, ревізійні голоси та окремий outcome. Механіка serverless authority (`OQ-0033`) і зміни policy під час pending запиту лишаються відкритими; fixtures не виконано.

[BMad post-commit effects kernel](../../_bmad-output/specs/spec-vida-post-commit-effects/SPEC.md) відокремив `REQ-EFFECT-007–011` від notification/approval: один похідний ресурс, відкладений незворотний effect, явний `effect.unknown`, correction для гілки поза confirmation frontier та звичайні права агента з додатковим conflict-context opt-in. EFF-F01–F17 є лише планом; executor, pin ревізії правила, provider retry і trigger API залишаються `OQ-0045/0048`.

[BMad mobile availability kernel](../../_bmad-output/specs/spec-vida-mobile-availability/SPEC.md) зводить AD-26/28, `REQ-ID-018` і `NFR-PLAT-009–012` в CAP-1–4 та AV-F01–F14: online-first без обіцянки 100% background, добровільний Android high-availability, iOS active-connection proof, Public-only consented push і заборона anonymous push binding. Пороги presence/retry, battery/data та force-stop UX залишаються `OQ-0064/0067/0076`; installed-build fixtures не виконані.

## Наступні залежні контури — рекомендація, не прийнятий порядок

Impact review 2026-09-25: core Release-1 scope тепер включає статичний Web із peer sync (`ADR-0021`), що замінює browser post-v1 boundary від 2026-09-22. Найближчі gates: Web Rust/Wasm + storage/security/relay/media/UX (`OQ-0035`, `OQ-0075`), operation envelope (`OQ-0028`), peer-equal conflicts (`OQ-0033/0034`), media (`OQ-0072`), collaborative Notes (`OQ-0073`), privacy/legal decisions (`OQ-0078`) і числові NFR (`OQ-0076`).

Попередні хвилі з відповідями: [decision-batch-2026-09-20.md](decision-batch-2026-09-20.md), [decision-batch-app-center-2026-09-20.md](decision-batch-app-center-2026-09-20.md) і [device-core batch](decision-batch-device-core-2026-09-20.md). Browser modes уже прийняті; paid business variants/retention відкладені, hosted trust і browser security лишаються окремими gates.
